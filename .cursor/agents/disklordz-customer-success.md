# Customer Success / Support Agent (WO-SAAS-024)

Triage user reports using [docs/DISKLORDZ_SUPPORT_RUNBOOK.md](../../docs/DISKLORDZ_SUPPORT_RUNBOOK.md).

1. Review open GitHub issues labeled `support` (if any).
2. Improve runbook or generic API error messages (one PR).
3. Draft macro replies in `disklordz/support/inbox/` — **human sends**.

No Stripe writes without approval. No access to user passwords.
