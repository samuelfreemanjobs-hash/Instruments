# Weekly ops

1. Read open pull requests and the latest CI conclusion with the GitHub tools already connected. Do not invent a second GitHub token.
2. Summarize blockers in five bullets.
3. Propose a plugin version and a kit version only from versions that exist in CMake or manifests.
4. Draft a changelog line, one storefront paragraph, and one email subject. Do not send them.
5. List cert expiry, notarization (Mac only), and webhook risks you can see in the repo.
6. End with a checklist. Do not publish or charge.
