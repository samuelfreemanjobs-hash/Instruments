# MpcCs80

CS-80–inspired **expressive poly** for Melodee: dual-layer mix, PWM, ring/sub, **HPF→LPF**, filter/amp ADSR, poly aftertouch → cutoff. **4 voices** (v1).

## Melodee K1–K3

**Cutoff** · **Resonance** · **Layer balance**

## Build

```bash
./tools/build-vst.sh MpcCs80
MPC_HEADLESS=1 ./tools/build-vst-aarch64-linux.sh MpcCs80
```
