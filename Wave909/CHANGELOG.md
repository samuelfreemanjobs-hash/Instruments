# Changelog — WAVE-909

## 0.1.0 — 2026-09-18

### Added

- Sampleless 64-wave hybrid engine with sub oscillator and tape wobble macro.
- Pristine ZDF lowpass and destructive drive/crush circuit.
- Eight factory presets for trap/phonk workflows.
- VST3, CLAP, and Standalone targets.
- `Wave909OfflineRender`, golden regression suite, state persistence tests.
- Resizable dark UI with full amp and filter envelope controls.

### Known limitations

- User wavetable import (planned P1).
- Full modulation matrix UI (planned P1).
