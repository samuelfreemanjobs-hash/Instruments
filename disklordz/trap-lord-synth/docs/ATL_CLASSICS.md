# ATL Classics sound bank

Original synthesis only. Preset and file names use neutral descriptive language (no artist or producer references).

## Sound-design modes

| Mode | Character |
|------|-----------|
| **Church Keys** | Gospel keys, organs, bells, warm EPs |
| **Dark Brass** | Dark brass, aggressive leads, ominous synth strings |
| **Trap Orchestra** | Dramatic strings, hits, layered brass, cinematic textures |

Use the **Sound bank** selector for quick ATL-style grouping. The main factory library ships **500** neutral presets in **12 browser categories** (Pads, Leads, Synth Keys, Swells, Brass, Strings, Church Keys/EP, Organ, Bells, Bass, Choir, Hits/FX). On **Swells** patches, the mod wheel deepens filter and amplitude swells.

## Global macros

| Macro | Effect |
|-------|--------|
| **Darkness** | Lowers cutoff, adds filter emphasis, increases reverb damping |
| **Dirt** | Drive and saturation |
| **Movement** | Chorus depth, vibrato, rotary speaker, extra detune |
| **Space** | Reverb wet level and delay mix |

## Flagship patch recipes

1. **Dirty Trap Brass** — detuned saws, 2.4 kHz LP, pitch envelope +3 semitone / 45 ms, saturation, room reverb.
2. **Church Keys** family — Bright EP + bell timbres; minor 7 / minor 9 chord modes on select presets.
3. **Evil Analog Lead** — narrow pulse, resonance, portamento, light distortion.
4. **Haunted Trap Bells** — inharmonic FM, short decay, long dark reverb.
5. **Southern Church Organ** — drawbar-style organ, vibrato, rotary speaker via Movement macro.
6. **Dark Orchestral Strings** — layered detuned saws, slow attack, chorus, lowpass.
