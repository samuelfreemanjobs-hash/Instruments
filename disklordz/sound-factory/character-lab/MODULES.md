# Hardware Character Lab — Module Registry

Original algorithms modeling **sonic character classes** (not trademarked product clones).

| module_id | Description | Typical use |
|-----------|-------------|-------------|
| `12-bit` | Quantization + jitter | digital drums |
| `8-bit` | Aggressive reduction | lo-fi |
| `early-rompler` | Band-limit + noise floor | 90s keys |
| `cheap-dac` | HF rolloff + distortion | sampler feel |
| `sampler` | Envelope + click | one-shots |
| `early-digital-reverb` | Short grain reverb | drums |
| `old-drum-machine` | Punch + saturation curve | kicks |
| `tape` | Soft clip + wow optional | warmth |
| `cassette` | Hiss + bandwidth | lo-fi |
| `sp-resample` | Down-up sample chain | SP-style |
| `mpc-workflow` | Trim + drive staging | MPC-style |

Each module exposes parameters for Plugin Kernel DSP wiring and Sound Factory batch processing.
