# Factory jobs (Phase 1 queue)

Drop `*.json` job files here for the Instrument Sound Factory worker. Schema and pipeline: [docs/INSTRUMENT_SOUND_FACTORY_AGENT.md](../../../docs/INSTRUMENT_SOUND_FACTORY_AGENT.md).

Example: `example-drum-batch.json` (safe to run offline).

Outputs go to `../out/<jobId>/` (gitignored).
