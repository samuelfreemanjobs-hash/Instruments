# Pluggnb Vital Preset Pack — product spec

## Vision

Ship **Instruments’ first preset pack**: a Vital bank built for **Pluggnb** producers who want ready-made melody and texture patches that fit modern plugg mix aesthetics (space, detune, soft transients, 808-friendly low end).

## Target user

Beatmakers working in Pluggnb / plugg-adjacent trap who use **Vital** as the main melodic synth.

## Sonic goals

| Element | Direction |
|---------|-----------|
| Bells / plucks | Wide stereo, light detune, short-to-medium decay |
| Keys / pads | Airy, chorus/unison-friendly, not muddy sub build-up |
| Bass / sub layers | Controlled sub for 808 pairing; avoid fighting kick/sub |
| Leads | Simple mono-ish hooks when needed; FX sends friendly |

## Non-goals

- Generic “all genres” mega-pack in v1  
- SP-1200 emulation in Vital (different SKU: SP-1200 VST)  
- WAVE-909 overlap (sampleless hybrid synth is a separate product)
