# Agent memory — index

Repo-wide memory for **every** agent (Cursor IDE, Cloud, CLI, profit agents). It lives in git so a fresh clone has it. Procedure: [SOP-019 Agent memory](../../../docs/disklordz/sops/SOP-019-agent-memory.md). Tool: `scripts/agent_memory.py`.

This file stays ≤ 200 lines: pointers and the hot list only. Detail lives in the entry files.

## Session protocol

1. **Start:** `python3 scripts/agent_memory.py recall --agent <your-id> <task keywords>` and read the "Always load" list below.
2. **During:** when something fails in a way a future agent could hit, note it.
3. **End (before reporting done):** for each *new, verified* lesson run `python3 scripts/agent_memory.py add …` (learning = reusable rule; incident = dated problem + fix). Then `python3 scripts/agent_memory.py check` must pass. Commit memory with your change.
4. **Promote:** when a lesson is hit a second time, turn it into an SOP step, rule, test or script, then `agent_memory.py promote <ID> --agent <id> --to <path>`.

Agent ids: `shared` (anyone), profit agents by folder name (`disklordz/agents/profit/<id>/`), e.g. `vst-factory-director` for factory, plugin and design-system work.

## What to memorize

- Failures with a non-obvious cause, and the exact fix (commands, flags, file paths).
- Environment facts that cost time (tool scopes, CI quirks, OS differences).
- Review findings that tests missed.

## Never memorize

- Secrets, tokens, webhook URLs, personal data (`check` scans for common secret formats).
- Anything derivable from git log, `ARCHITECTURE.md`, SOPs or code: link to it instead.
- Opinions without evidence. Every entry has `confidence: executed | inspected | assumed`.

## Always load

- **Review artefacts, not just test results:** open renders/outputs and compare states; tests passed on corrupt PNGs. vst-factory-director_learnings:L-0005
- **Merges need explicit operator approval** for each PR; give the exact list and order. shared_learnings:L-0003
- **Windows operator:** PowerShell `$env:X` (not `export`), `.sh` via Git Bash, one worktree per task, build one target. shared_learnings:L-0001
- **This laptop's GitHub token cannot push `.github/workflows/*`:** route workflow edits through a Cloud agent. shared_learnings:L-0002
- **JUCE version is pinned in `/JUCE_VERSION` (7.0.12);** root CMake uses 8.0.15. Build against the pin; guard JUCE-8-only APIs. vst-factory-director_learnings:L-0002
- **JUCE `FileOutputStream` appends** to existing files: delete or truncate first. vst-factory-director_learnings:L-0001
- **Non-ASCII UI strings** (·, −, ∞) need `juce::CharPointer_UTF8`. vst-factory-director_learnings:L-0003
- **Delegate shared-component fixes to the component's owner,** not the consumer; split agents by owned paths. vst-factory-director_learnings:L-0011
