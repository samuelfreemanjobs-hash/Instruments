Lofi-12 step sequencer

4×16 · Web MIDI → Lofi-12 · CC map

Connect MIDI OUT to Lofi-12 MIDI IN.

Setup

  1. USB-MIDI interface: computer OUT → Lofi-12 MIDI IN.
  2. On Lofi-12: enable MIDI receive; load phonk bank on slots 1–16.
  3. Track 1 supports sound lock: shift+click a step to pick sample slot 1–16.
  4. Match slot notes: slot N → MIDI note 35+N (default 36–51).
