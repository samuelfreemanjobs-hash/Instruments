# Memphis style presets (DiskLordz factory)

Factory modes in `factory_modes.py` are the canonical product ids. Optional style preset `memphis_insanity_pack` maps to `memphis_underground`.

Neutral engine ids: `hard_dirt_808`, `traproom_tape`, `tape_slowdown`, `tr808`, `tr909`, …

Neutral lane ids: `bounce_cowbell`, `hard_dirt_808`, `traproom_tape`, `tape_lag`, `sparse_machine_grid`, `slow_hat_drag`, `deep_knock_memphis`, `ultra_slow_bounce`, `horror_memphis`, `blackout`.

Artist or label strings are blocked by `factory_neutral_policy.py` and `tests/test_neutral_naming_policy.py`.
