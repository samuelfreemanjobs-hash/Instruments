# DiskLordz Audio Command

PWA + scripts for executing the [DiskLordz Audio master plan](../../docs/DISKLORDZ_MASTER_PLAN.md).

1. Open `pwa/index.html` via a local server (see [ARCHITECTURE.md](ARCHITECTURE.md)).
2. Check off the **Milestone 001 / 30-day sprint** items; progress saves in your browser.
3. Run `python3 scripts/weekly_review.py --write` before your weekly review.
4. Chat with the **audio-business-copilot** agent (skill `disklordz-audio-business-copilot`) for planning — route C++ work to Cursor separately.
