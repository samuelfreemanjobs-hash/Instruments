# Local clones — external logue reference (optional)

This directory is **gitignored**. Clone third-party repos here for **personal study** — they are **not** part of the Instruments product tree.

```bash
mkdir -p reference/logue && cd reference/logue

git clone --depth 1 https://github.com/peterall/junologue-chorus.git
git clone --depth 1 https://github.com/peterall/cloudlogue-reverb.git
git clone --depth 1 https://github.com/boochow/Waves2.git
git clone --depth 1 https://github.com/dukesrg/logue-fx.git
git clone --depth 1 https://github.com/ttaschke/tremoxd.git
git clone --depth 1 https://github.com/dukesrg/logue-osc.git
```
