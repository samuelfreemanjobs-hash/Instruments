# DiskLordz Audio — brand identity (v1)

**Status:** Owner references on file — ready for plugin UI + store.

## Company name

**DiskLordz Audio** — wordmark **DiskLordz** (one word, blackletter / Old English)

## Tagline (draft)

Built for the Underground. Trap, phonk, and hip-hop production tools that ship fast.

- Dark chrome (`#0A0A0C`), purple highlights, lime for “go” controls
