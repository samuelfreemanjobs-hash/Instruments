# DL002 — Midnight Circuit (drift · wave phonk)

## Lane archaeology

Midnight Circuit deconstructs **Memphis cassette phonk**, **playa soul contrast**, and **cloud/trill phonk** for **fast** distribution (**140–160 BPM**) — gym, night drive, FPS. Source remains **1970s–1980s soul, jazz-funk, R&B stabs**; processing is **regional hip-hop archaeology**, not generic trap.

### Movement A — Memphis 90s (cassette)

| Element | Detail |
|---------|--------|
| Drums | **Boss DR-660/DR-5** — frantic **808-style hi-hat rolls**, deep sine kicks |
| Samplers | **Gemini DS-1224**, **E-mu SP-1200** @ 12-bit, 26.04 kHz, **SSM2044** LP |
| Sample method | **45 RPM** sample → internal pitch down → ring-aliasing, mid grit |
| Aesthetic | Orchestral **melancholic soul** loops vs **raw percussion** — lavish vs aggressive |

### Movement B — Cloud / DJ Smokey lineage

| Element | Detail |
|---------|--------|
| Source | Modal **jazz-funk**, library music, **quiet storm Rhodes** |
| Processing | **Sidechain ducking**, **bitcrush**, **tape-stop**, resonant **digital LP filter** |
| Overlay | **Syncopated 808** patterns, cowbell/wave leads (drift phonk) |
| Harmony | **Suspended minor**, airy Rhodes required |

### Drift / wave phonk (distribution)

- **808 sub glides**, Memphis **vocal chop** behavior, **cowbell arps**, tape saturation  
- **Wave phonk** melodic top lines over drift drum density  
- **Forbidden:** screw slowdown identity (DL006), French touch 909 pump (DL001)  

### Source session → lane transform

1. Source **68–92** with soul/jazz-funk clarity.  
2. Section JSON: `memphis_90s` and/or `cloud_phonk`.  
3. Guardian validates **140–160** and chop length for Shorts.  
4. Compiled prompt embeds SP-1200/DR-660 + Smokey processing flags.
