# JD Upgraded — architecture

## Phase 1 — audio core

- **Processor** → `VoicePool::render` with preallocated `outputScratch_` (no heap on the audio thread).
- **Voices** — 32 × 4 `Tone` instances; `RateLevelEnvelope` at `kControlRateDivisor` (32 samples).
- **PCM** — `SampleEngine` + `RomBank` or `CleanroomWaveLibrary` fallback.

## Phase 2 — JD-style DSP

- **ZDF TVF** (`Filter/ZdfTvf.h`) per tone.
- **Coupling** — ring, cross-mod, hard sync (`ToneCouplingMode`, `PolyBlep`).
- **Master FX** — `GroupADistortion`, `GroupBSpatial`.

## Phase 3 — ROM & programs

- **ROM v2** — `jdupg_cleanroom.rom`, 256 waves, generated by `tools/GenerateCleanroomRom.cpp`.
- **128 programs** — `FactoryPatchLibrary`; `currentProgram` in saved state.
- **RomLoader** — embedded ROM; optional `JDUPGRADED_ROM_PATH` ([USER_ROM.md](USER_ROM.md)).
- **SysEx** — `SysExParser`, `JdPatchSysexMapper` (384-byte JD patch → APVTS).

## Phase 4 — polish & harness

- **SIMD** — `Simd/VoiceSimd.h` (AVX2 / NEON).
- **UI** — programs, tones (level/wave/MS/mute), filter, Group A/B, coupling, envelopes (link + per-tone), wave palette.
- **Tools** — `OfflineRender`, `SpectralDiff`; CI determinism check ([AB_HARNESS.md](AB_HARNESS.md)).
