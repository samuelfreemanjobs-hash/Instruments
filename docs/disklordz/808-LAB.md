## One pipeline, three surfaces

```text
lane-registry + factory WAV + verify:spark + manifest
  → Akai MPC500     (performance: chop, sequence, sample playback)
  → Arturia SparkLE (companion MIDI: PC engine params, FX, experimental control)
  → Windows PC      (Chop Machine, phonk/808 synth, soul chords, screw/tape — intelligence)
```

**MIDI** = clock, notes, CC. **Audio** = separate routing (interface / mixer / DAW).

Pack line: *“Built in DiskLordz 808 Lab — SparkLE manifest included.”*
