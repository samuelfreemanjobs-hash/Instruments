## One pipeline, two surfaces (your setup)

```text
lane-registry + factory WAV + verify:spark + manifest
  → Akai MPC500  (chop, sequence, sample playback)
  → Windows PC   (kit export, phonk_engine, future chop/synth/screw)
```

Optional third surface: **SparkLE** USB MIDI for PC params only.

**MIDI** = clock, notes, CC. **Audio** = separate routing (PC out / interface / MPC mix).

Pack line: *“Built in DiskLordz 808 Lab — MPC-ready manifest included.”*
