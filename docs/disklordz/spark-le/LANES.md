## Contract hints (Phase 2)

| Family | Emphasis |
|--------|----------|
| Memphis | SNARE-STACK dirt; dark HAT-CLARITY |
| Atlanta / gangsta | KNOCK vs SUB separation; clapWide on trunk lanes |
| Shawty Redd | LOOP-GRID swing; body snare |
| Hardware | Short KNOCK decay; DR-660 vs 808-CLONE peak bands |
| Rage | Minimal hatDecay; low 808 sustain |
| Bay vs Detroit | Bay brighter hats; Detroit harder snap |
| Trap producer | 808-MAFIA low pitch; CARDO longer decay |
| Smooth / jetlife | Lower snareSnap; higher rim on jazz lane |
| Strip anthem | clapWide max; loop-forward |
| TR-909 vs 808 | 909 shorter decay band vs 808-CLONE sub |
| Houston / screw | DJ-SCREW long decay; low hatBright |
| Detroit street | Snap-forward; DOUGHBOYZ body snare |
| Cloud | High hatBright; lower snareSnap |
| Lex Luger | SNARE-STACK near max snap |
| Boss trap | Long kickDecay; Ross body snare |
| Phonk/wave | DRIFT-PHONK cowbell; WAVE hatBright |
| Carti vs Pierre | Carti shorter decay; Pierre softer snap |
