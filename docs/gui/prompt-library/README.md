# GUI prompt library (Gemini / AI Studio / Stitch)

Save **reusable prompts** here (no secrets). Copy into Google AI Studio or Stitch when starting a new screen.

## Suggested files

| File | Use |
|------|-----|
| `explore-layouts.md` | “Give 3 desktop layouts for …” |
| `copy-deck.md` | Labels, hints, errors as markdown tables |
| `stitch-phonk-sequencer.md` | Stitch-specific prompt for dark Memphis studio UI |

## Example (explore)

```text
Product: 6-track × 16-step drum sequencer + drum loop factory.
Constraints: desktop 1100px, dark theme, purple accent, Lofi-12 hardware = 4 tracks.
Output: section list top-to-bottom, then wireframe ASCII for each section.
Do not use trademarked product UIs.
```

After a good run, paste the output into the product `GUI_MOCKUP_SPEC.md` or a PR comment.
