# DISKLORDZ workforce — agents vs workers

## Short answer

You do **not** need a army of **human** employees to launch. You **do** need a **full roster of specialized agents** (docs + prompts + automation) and **one human** (you) for taste/legal/final veto.

**More “workers”** usually means:

| Type | When to add | Cost |
|------|-------------|------|
| **Subagent prompts** (email, DR, artist lane, QC) | Now — already in repo | Free |
| **Cursor Cloud runs** (Factory batch, website WOs) | Per WO — you already have this | Subscription |
| **Parallel Cloud agents** | Only if >2 heavy JUCE WOs at once | Same sub, queue time |
| **OpenClaw / local IDE** | Artist compile sessions on your PC | Your machine |
| **Human hire** (mix engineer, VA editor) | After revenue — optional | $ |

Adding agent **roles** is cheap. Adding **parallel implementation** hits WIP limits (max 2 JUCE WOs). Marketing + A&R are mostly **parallel** to engineering.

## When to add real headcount

- **>2 launches/month** with video editing backlog → part-time editor  
- **Support tickets** >30/week → Crisp + VA  
- **Custom plugin DSP** beyond Track E → dedicated DSP contractor  

Until then: **expand agents, not payroll**.
