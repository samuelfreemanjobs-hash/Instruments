# Product JZ400 — Young Jeezy type multisample library

**Target:** 400 **non-drum** instruments (808 bass allowed), indexed by album/mixtape track + archetype.  
**Sound source:** Clean-room **trap_synth** multisamples — not master recordings.  
**Exports per instrument:** `instrument-map.json`, **SFZ**, MPC Keygroup handoff (MPCTK + Cursor MPC-agent).

## Catalog

```bash
python3 disklordz/sound-factory/scripts/seed_jz400_catalog.py --target 400
# → disklordz/sound-factory/catalog/jz400_catalog.json
```

Album/track index: `disklordz/sound-factory/catalog/jz400_albums.json` (expand with mixtapes over WOs).

## Batch render

```bash
python3 disklordz/sound-factory/scripts/run_product_batch.py \
  --catalog disklordz/sound-factory/catalog/jz400_catalog.json \
  --out disklordz/sound-factory/out \
  --offset 0 --limit 50
```

## QA

Every WAV passes `factory_qa.py`. Failed slots are dropped from batch summary; re-run with fixed seed/lane.

## Reference workflow

Optional YouTube segment per slot (`referenceQuery` in catalog) via skill `sound-design-reference-match` — tune `trap_synth` params before render (WO-SF-030).
