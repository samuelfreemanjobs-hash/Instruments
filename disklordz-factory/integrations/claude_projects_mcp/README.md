# claude-projects MCP server

Read-only MCP tools over Claude Code’s on-disk workspaces (`~/.claude/projects` by default).

## Setup

```bash
./setup.sh
```

## Tools

- `claude_projects_root`
- `list_claude_projects`
- `search_claude_projects`
- `list_claude_project_files`
- `read_claude_project_file`
- `export_claude_project_manifest`

See [docs/CLAUDE_MCP.md](../../../docs/CLAUDE_MCP.md).
