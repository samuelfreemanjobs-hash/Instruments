# Night Circuit — preset sound-design ownership

The **1,028** factory bank is **21 authored foundations** plus deterministic variations. QA can prove integrity; **musical quality** needs a sound-design owner alongside QA.

**Agent prompt:** [../../docs/NIGHT_CIRCUIT_SOUND_DESIGN_SUBAGENT.md](../../docs/NIGHT_CIRCUIT_SOUND_DESIGN_SUBAGENT.md) · **Cursor:** [../../.cursor/agents/night-circuit-sound-design.md](../../.cursor/agents/night-circuit-sound-design.md)

**Product format:** desktop **VST3** for **FL Studio** and **MPC Software** (desktop). Cursor VM builds do not substitute for host testing — see [HOST_COMPATIBILITY.md](HOST_COMPATIBILITY.md).

## Responsibilities

- Review factory presets **by category** (Bass → Synth → Lead → Pad → Pluck/Keys).
- Retune or replace weak variations; keep **1,028** total unless product approves otherwise.
- Curate **50–100 featured** programs so users are not forced to browse 245 Synth entries blindly.
- Document renames and gain changes (no global loudness normalize unless intentional).

## Handoff from QA

QA delivers flagged lists (silence, clipping, outliers, stuck-tail renders). Sound-design lead decides keep / retune / replace.

## Acceptance (Phase 3 gate)

- Featured set approved for shipping UI default.
- No known silent or broken factory programs.
- Category roles match [PRESET_CATEGORIES.md](PRESET_CATEGORIES.md).
