# Night Circuit — preset categories (Milestone 1)

**Policy:** **Synthetic only.** Categories describe **mix roles** in trap/vaporwave production—not acoustic instrument types. No piano, guitar, orchestra, or sample-based factory programs.

Five **factory** mix roles + **User** bank.

| Category | Job |
|----------|-----|
| **Bass** | Sub / low single-note weight |
| **Synth** | **Poly chords & melodic beds** (vaporwave, Jeezy stacks) |
| **Lead** | Hooks, mono-forward lines, FX-ish sweeps |
| **Pad** | Slow atmosphere |
| **Pluck/Keys** | Short rhythmic stabs & key lines |
| **User** | Saved patches (disk) |

Keys and Synth FX factory tags were merged into **Synth** / **Lead** for v0.1 clarity.
