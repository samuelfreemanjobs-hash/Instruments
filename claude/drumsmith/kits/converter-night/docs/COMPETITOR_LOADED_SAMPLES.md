## Competitive pattern (what they sell that buyers expect)

1. **Same-hit parallel banks** — clean / tape / lo-fi of *the same* drum set (not just one “dust” folder).
2. **Named hardware story** — V1 = DR-5, V2 = SP-1200 (CNV’s DR-660 crawl is a *different* lane; do not copy their claims).
3. **Instrument one-shots** (V1×82) — melodic/perc beds so producers can finish a beat without a second pack.
4. **BPM-labeled construction loops** (V2×23) — fewer than CNV’s 36, but marketed as lo-fi processed loops.
5. **PDF education** as SKU glue — mixing tips / VST list (CNV already has `Hardware_Processing_Guide.md`).
6. **Price band** $25–$30 for pure drum kits; $50 for melody-heavy Lo-Fi Memphis.

### CNV strengths to keep

- Higher FX surface (crash / alias / reverse / stab / texture).
- Explicit Memphis archetype loops (crawl / bitcrush / horror / bounce).
- Original synthesis provenance (no clearance theater).
