# Converter Night — hardware / DAW processing guide

Techniques for producers. Not clone recipes for any trademarked machine.

## Rate-drop subs

1. Start from a solid kick or 808-character body (or use `02/Pitched_Sub_Basses`).
2. Pitch down hard (−12 to −24 st feel) or slow playback so the fundamental crawls.
3. Shorten with a fast release / choke so long notes don’t smear.
4. Add mild drive or soft clip for converter grit; keep mono for center weight.

## Tape and converter grit

- Soft clip → gentle HF roll-off → optional vinyl/dust layer from `04/`.
- Prefer short decays on snares/hats so cassette compression stays punchy.
- Layer EDGE closed hats over RATE sub beds for the Memphis “cut” — two layers, not one ROM.

## Aliased / pitched one-shots

- Use `02/Aliased_One_Shots` as color, not the whole groove.
- Re-pitch in your sampler; watch for digital trash that fights the kick.

## Loops (DR-660–style language)

- Rhythm loops at **94** BPM (tape creep) or **134** half-time feel.
- Prefer **pitched long subs as bassline**, **cowbell/clave-bell motifs**, sparse kick, half-time snare, thin hats — drums-first, no piano bed.
- Pack includes original `cnv-dr660-*` blueprints (`recipes/DR660_LOOPS.md`); not Boss ROM patterns.
- Top loops: hat/perc 16ths — mute or filter for arrangement, don’t brick-wall.

## Device notes

Import as generic PCM16 WAV. MPC / Maschine+ / SP-404 / Lofi-12 / MV-1 paths are **UNVERIFIED** until a real device test is logged in provenance.
