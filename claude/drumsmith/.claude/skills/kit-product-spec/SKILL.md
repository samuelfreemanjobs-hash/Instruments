# Product specification contract
Generate SKU, target beatmaker/genres, positioning, sonic palette, competitor differentiation without cloning, price hypothesis (human approval), categorized hit list, minimum variations and naming schema `<SKU>_<CATEGORY>_<DESCRIPTOR>_<KEY-or-NA>_<INDEX>.wav`.

Use folder layout `masters/`, `exports/<verified-profile>/`, `docs/`, `previews/`. Each master has stable id, WAV path, target duration/format, voice recipe id, random seed, lineage, license and tuning targets. Do not promise a device export until its file format and naming limitations are verified from primary docs or physical device tests. Store device tests in `docs/device-tests.md`.
