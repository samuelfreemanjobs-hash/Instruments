# V Voyager — Moog factory bank (300 programs)

**300** Voyager / Moog-style factory programs ship with the plugin.

| Range | Content |
|-------|---------|
| **001–024** | Core curated (Init, G-Funk, pads, FX, unison) |
| **025–032** | **Funk / 80s / Screw / Talkbox** (Parliament, Funkadelic, boogie & R&B bass, 80s lead, DJ Screw, Roger Troutman / Zapp) |
| **033–300** | Moog archetype variants (includes extra P-Funk, boogie, R&B, talkbox, screw lines in the long tail) |

Regenerate:

```bash
python3 plugin-factory/plugins/moog-voyager/scripts/generate_factory_presets.py
```
