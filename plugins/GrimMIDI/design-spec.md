# Grim-MIDI — design spec

**Theme:** DiskLordz underground violet on `#0b0c10` (matches launch dashboard).

## Layout (560×452)

- Header: title + progression preset combo (100 items, scrollable)
- Row 1: Key, Scale, Chord, Inversion, **Trigger Mode**
- Row 2: Spread, Strum, Vel Humanize, Octave rotary knobs
- Footer: **Drag MIDI to DAW** (external file drag of current progression)

## Interaction

- Program change applies preset scale/chord (and key when preset pins it).
- Trigger mode tooltip (future): Degree Pads = white keys as i–vii in selected key.
