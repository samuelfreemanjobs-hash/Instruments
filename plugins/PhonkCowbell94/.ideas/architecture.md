# PhonkCowbell94 — architecture

**Voices:** 12 poly + **mono legato glide** mode for cowbell leads.

**Layer A — 808 cowbell + sub**

- Dual square oscillators **f2/f1 ≈ 1.48** (808 ~540 Hz + ~800 Hz reference at middle C), pitch-tracked to MIDI (no WAV stretch).
- Resonant **bandpass** + snappy percussive amp decay (short env for cowbell; long env option for bass notes).
- Phase-locked sine/tri **808 sub** with pitch-drop envelope on note on.

**Layer B — Memphis atmosphere**

- Dark 5-vowel formant choir, horror bell WT, cassette hiss.

**FX:** 4-track cassette saturation chain, SP-1200 style decimate/quantize, dark hall.

**Macros:** Cowbell Bite, 808 Sub, Memphis Tape, SP-1200 Crunch, Tube Dirt, Choir Morph, Slap Echo, Crypt Reverb.

**UI:** Blood red, matte black, chrome tape.

**Presets (×12):** per factory prompt (Memphis 94 Cowbell, Drift King Lead, …).
