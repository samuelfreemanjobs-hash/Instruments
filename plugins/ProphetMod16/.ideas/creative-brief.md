# ProphetMod16 — creative brief

**Product:** 16-voice polyphonic analog-mod synth inspired by **Sequential Prophet ’08 / Rev2**.

**Audience:** Desktop producers wanting Rev2-style depth (dual osc, Curtis filter, deep mod) without owning hardware.

**Differentiator vs Prophet Rev2 Trap (repo):** Trap SKU is 8-voice, preset-focused, minimal UI. **ProphetMod16** adds **8-slot mod matrix**, **4 LFOs**, **aux envelope**, **unison/legato modes**, **chorus + tempo delay**, and a **WebView** Sequential-style panel.

**Not in v1 (optional v1.1):** Bi-timbral Layer A / B split-stack (Rev2 performance layout).

**Melodee:** Out of scope for this SKU — desktop JUCE 8 first; aarch64 headless variant only if spun as separate `Mpc*` later.
