# MpcLaSynth — parameters (v1)

Melodee **K1–K3** = IDs 1–3.

| # | ID | Name | Range | Default |
|---|-----|------|-------|---------|
| 1 | `body_level` | Body level | 0–1 | 0.85 |
| 2 | `attack_level` | Attack level | 0–1 | 0.7 |
| 3 | `cutoff` | TVF cutoff | 80 Hz–12 kHz | 6000 |
| 4 | `attack_wave` | Attack wave | 0–5 | 0 |
| 5 | `body_wave` | Body loop | 0–5 | 0 |
| 6 | `res` | Resonance | 0–1 | 0.1 |
| 7 | `attack_time` | Attack fade | 5–400 ms | 80 |
| 8 | `body_attack` | Body swell | 0–500 ms | 40 |
| 9 | `release` | Release | 10 ms–4 s | 400 |
| 10 | `tune` | Fine tune cents | ±100 | 0 |
| 11 | `pan` | Pan | −1–1 | 0 |
| 12 | `lfo_rate` | LFO | 0–8 Hz | 0 |
| 13 | `lfo_to_pitch` | LFO pitch | 0–1 | 0 |
| 14 | `chorus` | Chorus send | 0–1 | 0.2 |

**Attack wave index (factory):** Piano Click, Mallet, Bell Strike, Choir Ah, Brass Hit, Noise Tap.

**Body loop index:** House EP Loop, Soft Sine, Choir “Ah”, Bell Sustain, Organ Drawbar, Glass Pad.

**Programs:** House Piano, Airy Choir, Memphis Bell, Stack Brass, Init Layer.
