# MpcSh101 — creative brief

**Target:** Roland **SH-101** for **MPC Sample / Melodee**: **monophonic** punchy **bass and lead** — one **VCO** (saw / pulse + PWM), **sub-oscillator** (−1 oct square), **snappy** amp/filter envelopes, **portamento**, simple **12 dB–style** resonant VCF.

**CPU:** lighter than **MpcMinimoog** (single main osc + sub, no triple stack / ladder saturation by default).

**Host:** headless; **K1–K3** = **cutoff**, **resonance**, **sub level** (classic 101 performance layout).

**Feel:** tight attacks for acid/techno bass; short decay leads; optional PWM LFO in v1.1.
