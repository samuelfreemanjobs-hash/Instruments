# MpcMessenger — creative brief

**Moog Messenger**–inspired mono synth for Melodee: dual **morph + wavefold** VCOs, **FM 2→1**, sub square, noise, **LadderFilter** with **Res Bass** low-end restore, dual ADSR. K1=cutoff, K2=resonance, K3=res bass (or fold).

Loopable envelopes: v2 (custom EG); v1 uses standard ADSR.
