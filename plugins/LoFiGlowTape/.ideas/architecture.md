# LoFiGlowTape — architecture

**Genre:** Neo-soul, boom-bap, VHS keys.

**Layer A:** Rhodes/Wurlitzer tine + felt upright model + key-off thump.  
**Layer B:** Mellotron tape flute/strings, warm pad, vinyl crackle / tape hiss.  
**Filter:** Warm 12/24dB LP.  
**FX:** Cassette wow/flutter, 12-bit mu-law crunch (10–32 kHz decimate), spring + hall.  
**Macros:** Warmth, Wow/Flutter, 12-Bit Crunch, Tape Sat, Vinyl/Hiss, Swell, Warble Chorus, Space.

**UI:** Warm charcoal, amber-gold, cream. XY Y → tape cutoff + space.

**Presets (×12):** Dusty Rhodes 73, Cassette Felt Piano, Rainy Window Pad, 90s Boom-Bap Keys, Warbled Tape Flute, Neo-Soul Suitcase, 12-Bit Vinyl Bells, Midnight Study Chords, VHS Dream Organ, Mellow Sub & Keys, Analog Tape Choir, Crushed Lo-Fi Pluck.
