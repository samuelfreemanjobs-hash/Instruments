# SoulSessions70 — architecture

**Layer A (switchable):** Hammond B-3 drawbar tonewheel + key click; Hohner Clavinet D6 model.  
**Layer B:** Solina divide-down strings + warm analog brass ensemble.  
**Filter:** 12/24dB LP + **envelope auto-wah** mode (BPF + env follower).  
**FX:** Leslie rotary, 4-stage phaser, tape echo, spring reverb.  
**Macros:** Tone, Auto-Wah, Rotary/Chorus, Tube Grit, Phaser, Swell, Tape Echo, Spring Reverb.  
**UI:** Walnut, cream, burnt orange.  
**Presets (×12):** 70s Gospel B3, Superstition Auto-Wah, Motown Strings & Keys, …
